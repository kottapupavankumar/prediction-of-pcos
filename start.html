PREDICTION OF PCOS USING MACHINE LEARNING AND WEB APPLICATION

Polycystic Ovary Syndrome (PCOS) is a hormonal disorder affecting women of reproductive age. Hormonal imbalance leads to insulin resistance,causing the body to produce excess androgens. This disrupts ovulation, leading to irregular periods and cyst formation on the ovaries. Over time, this develops into PCOS.

"Project Process: From Concept to Completion"

Step 1: Data Collection

We obtained the PCOS dataset from Kaggle, which contains essential health parameters related to PCOS diagnosis. The dataset includes independent variables like age, BMI, and hormone levels, along with the target variable indicating PCOS presence. This data was selected to ensure reliability and relevance for model training.

Step 2: Data Cleaning

To improve model performance, we handled missing values, removed duplicates, and standardized numerical data using Pandas. We also performed feature selection to retain only the most relevant attributes, ensuring our dataset was clean and reliable for training.

Step 3: Model Building

Using Python and Scikit-learn, we built a Logistic Regression model to predict PCOS. The dataset was split into training and testing sets, and the model was trained to classify individuals based on input features. Our model with an accuracy of 88%, making it a reliable tool for PCOS prediction.

Step 4: Web Developement

We built a web application using Django. The web application allows users to input their health parameters and receive a predicted risk assessment for PCOS. We designed a user-friendly interface to facilitate easy data entry and result interpretation.

Conclusion

This project demonstrates how machine learning can assist in PCOS diagnosis by analyzing health related parameters. Our predictive model, with 88% accuracy, allows individuals to assess their risk of PCOS. Future improvements could include integrating advanced models or expanding the dataset.
